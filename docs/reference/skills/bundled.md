# Bundled Skills

Bundled skills are catalog entries that ship with Geetorus's baseline kit. They are versioned with the app, browseable through the catalog API, and installable into a company when a team needs that operating pattern.

For the catalog mechanics, start with the [Skills reference](../skills.md#3-app-shipped-catalog). For optional add-ons, see the [Optional skills](./optional.md) index.

## Docs

- [Doc Maintenance](./bundled/docs/doc-maintenance.md) — keep project documentation aligned with recent code and feature changes.

## Geetorus operations

- [Issue Triage](./bundled/geetorus-operations/issue-triage.md) — classify stale, blocked, in-review, or stalled Geetorus issues and choose the next action.
- [Status Card Query](./bundled/geetorus-operations/status-card-query.md) — author Geetorus status cards, and compile a card's prose prompt into bounded search queries and its first summary.
- [Task Planning](./bundled/geetorus-operations/task-planning.md) — turn approved plans into Geetorus issues with ownership, dependencies, and acceptance criteria.

## Product

- [Wireframe](./bundled/product/wireframe.md) — produce low-fidelity UI wireframes as standalone SVG deliverables.

## Quality

- [QA Acceptance](./bundled/quality/qa-acceptance.md) — define observable acceptance criteria and focused verification passes.

## Software development

- [GitHub PR Workflow](./bundled/software-development/github-pr-workflow.md) — prepare, inspect, update, and communicate GitHub pull request work.
